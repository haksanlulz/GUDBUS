# GUDBUS wiki

GUDBUS is an unofficial Discord table aid for GURPS 4e. The [README](https://github.com/haksanlulz/GUDBUS#readme) covers what it is and how to run it; these pages hold the detail.

- [Commands](Commands): every slash command, by area
- [A session](A-Session): one combat, start to finish, as the bot renders it
- [Reference data](Reference-Data): where `/skill`, `/spell` and the other lookups get their facts
- [Architecture](Architecture): the package layout
- [Development](Development): migrations, tests, and the test layers

Hosting your own instance: [DEPLOY.md](https://github.com/haksanlulz/GUDBUS/blob/main/DEPLOY.md).
